## Status Definitions

| Status | Meaning |
|--------|---------|
| Active | Current, governing document — use this version |
| Draft | Under review — do not act on it yet |
| Superseded | Replaced by a newer version — retain for reference only |
| Archived | No longer relevant — moved to 99_Archive in Drive |

---

## Registration Protocol

When a new document is created:

1. Add a row to the appropriate table above
2. Fill in all location fields (Local, GitHub, Drive) once each is confirmed
3. Set Status to `Draft` until reviewed; change to `Active` when adopted
4. Commit this file alongside the new document

When a document is updated:

1. Increment the version number
2. Update the Last Updated date
3. If the update changes strategy (not tactics): update ELBOLD_MASTER_PLAYBOOK.md too

When a document is retired:

1. Change Status to `Archived`
2. Move the Drive copy to `99_Archive`
3. Add a note in the table: "Superseded by [document name]"

---

*This registry is only useful if it is kept current. Update it every time a document is created, changed, or retired.*
