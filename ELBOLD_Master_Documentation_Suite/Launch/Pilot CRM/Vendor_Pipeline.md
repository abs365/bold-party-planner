## Pipeline Stage Definitions

| Stage | Definition |
|---|---|
| **Prospect** | Identified from lead list, not yet contacted |
| **Contacted** | Outreach sent (WhatsApp / Email / Instagram DM) |
| **Responded** | Vendor replied — interested or declined |
| **Interested** | Expressed willingness to join |
| **Applied** | Application submitted via `/vendor/apply` |
| **Approved** | Admin approved — email confirmation sent |
| **Profile Building** | Actively completing vendor profile |
| **Visible** | Profile > 60%, appears in marketplace |
| **Lead Received** | First RFQ received from a customer |
| **Quote Sent** | Responded to at least one RFQ |
| **Booked** | First booking confirmed |
| **Verified** | Verification Level 2+ achieved |
